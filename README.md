# Passe-Marée

Appli web installable (iPhone et Android) : place un point sur la carte, la sonde est récupérée automatiquement (EMODnet), la marée est prédite (Open-Meteo, calée sur Roscoff) et l'appli donne les créneaux où ton bateau passe.

Données : © OpenStreetMap, © OpenSeaMap, EMODnet Bathymétrie, Open-Meteo. Aide au calcul, pas un instrument de navigation.
